# Domain Interview Bot

A Telegram bot for conducting structured domain interviews and collecting software requirements.

The project aims to provide a simple and organized way to gather information from domain experts during the early stages of software development.

## Project Status

This project is currently in early development.

## Development

### Requirements

- Python 3.12 or later
- [uv](https://docs.astral.sh/uv/)

### Setup

Clone the repository and navigate to the project directory:

```bash
git clone https://github.com/maxshouman/domain-interview-bot.git
cd domain-interview-bot
```

Install the project and its development dependencies:

```bash
uv sync
```

### Run the application

```bash
uv run domain-interview-bot
```
